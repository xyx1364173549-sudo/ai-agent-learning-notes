LangGraph 重构 Agent

任务 1.5 · 学习笔记 · 2026-08-25 · 阶段一收官之作

一句话总结：把 mini_agent 的手写 while 循环，改造成 LangGraph 状态图——用"节点 + 条件边"表达"下令 → 执行 → 回答"的 Agent 循环。

一、Agent 循环

① 手写循环 → 状态图

START→ call_model→ 有工具?→ tool_node

tool_node 执行完回到 call_model 形成"环"，无工具则 END

② Annotated + add_messages —— 消息累加

class AgentState(TypedDict):
    messages: Annotated[list, add_messages]   # 累加，不是覆盖

类比：默认覆盖=换新纸；add_messages=在同一个本子上往下写

二、三个节点/函数

③ call_model —— 调 LLM

def call_model(state):
    response = llm_with_tools.invoke(state["messages"])
    return {"messages": [response]}

第1次 content 空（下令），第2次 content 正常（回答）

④ tool_node —— 执行工具（按 name 分发）

TOOLS = {"get_weather_tool": get_weather_tool,
         "calculator_tool": calculator_tool}

def tool_node(state):
    msg = state["messages"][-1]
    tool_messages = []
    for tool_call in msg.tool_calls:
        tool = TOOLS[tool_call["name"]]         # 按 name 分发
        result = tool.invoke(tool_call["args"])   # args 是字典
        tool_messages.append(ToolMessage(content=result, tool_call_id=tool_call["id"]))
    return {"messages": tool_messages}          # 要 return！

⑤ should_continue —— 方向代号（不是节点名）

def should_continue(state):
    if state["messages"][-1].tool_calls:
        return "continue"    # 方向代号
    return "finish"

graph.add_conditional_edges("call_model", should_continue,
    {"continue": "tool_node", "finish": END})

三、两个核心坑

⑥ 节点名三处一致（本任务最大的坑）

graph.add_node("tool_node", tool_node)              # ① 注册
graph.add_conditional_edges(..., {"continue": "tool_node", ...})  # ② 映射
graph.add_edge("tool_node", "call_model")           # ③ 连边

三处 "tool_node" 必须一字不差（本次踩坑 "tools"/"tool"/"tool_node" 打架）

⑦ 循环自动终止

第 2 次 call_model 时 AI 已拿到工具结果，不再"下令"而是"回答"（无 tool_calls），should_continue 返回 finish，结束循环。
