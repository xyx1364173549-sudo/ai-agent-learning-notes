### 模块 2：WeatherClient 类骨架（20分钟）
**功能：** 类的四大基础方法
**知识点：** 类 `__init__`、`__str__`/`__repr__`（`!r` 带引号）、`requests.get`
**踩过的坑：** `rsplit("/")` 返回列表！要用 `rstrip("/")`（去末尾斜杠防双斜杠）

```python
class WeatherClient:
    def __init__(self, base_url: str = "https://wttr.in"):
        self.base_url = base_url.rstrip("/")    # 去末尾斜杠

    def __str__(self) -> str:
        return f"WeatherClient(base_url={self.base_url})"

    def __repr__(self) -> str:
        return f"WeatherClient(base_url={self.base_url!r})"   # !r 带引号
```

### 模块 3：异常处理增强（25分钟）
**功能：** 网络请求的完整异常处理
**知识点：** `try-except`、`raise_for_status()`、`requests.exceptions` 异常
**踩过的坑（重要！）：**
- 异常类**必须从 `requests.exceptions` 导入**——内置 `TimeoutError`/`urllib3` 的异常**接不住** requests 的异常！
- `except` 里的名字要和 `import` 的名字**完全一致**（`except Timeout` 不是 `except TimeoutError`）

```python
from requests.exceptions import Timeout, ConnectionError, HTTPError   # ✅ 必须这样导入！

def get_weather(self, city: str) -> dict | None:
    try:
        resp = requests.get(url, params=params, timeout=10)
        resp.raise_for_status()      # 4xx/5xx 自动抛异常
        return resp.json()
    except Timeout:
        print("[错误] 请求超时")
    except ConnectionError:
        print("[错误] 网络连接失败")
    except HTTPError as e:
        print(f"[错误] HTTP {e.response.status_code}")
    except ValueError:
        print("[错误] 响应不是合法 JSON")
    return None
```

### 模块 4：数据格式化展示（20分钟）
**功能：** 从几百行 JSON 里提取 城市/温度/天气/湿度
**知识点：** 嵌套字典访问、链式 `.get()`、f-string
**踩过的坑（重要！）：**
- **嵌套结构**：`current_condition` 是**列表**，要 `[0]` 取第一个；城市名藏在 `nearest_area[0]["areaName"][0]["value"]`（剥两层）
- **`{}` vs `[{}]`**：后面要 `[0]`，默认值必须用 `[{}]`（列表），用 `{}`（字典）会 `KeyError: 0`！
- **字段名要对着真实 JSON 看**：`temp_C` 不是 `temp`，拼写 `value` 不是 `vlaue`

```python
def format_weather(data: dict) -> str:
    current = data.get("current_condition", [{}])[0]   # 列表取第一个
    area = data.get("nearest_area", [{}])[0]

    city = area.get("areaName", [{}])[0].get("value", "未知")
    temp = current.get("temp_C", "?")
    desc = current.get("weatherDesc", [{}])[0].get("value", "未知")
    humidity = current.get("humidity", "?")

    return (f"城市: {city}\n" f"温度: {temp}°C\n" f"天气: {desc}\n" f"湿度: {humidity}%")
```

### 模块 5：文件持久化（15分钟）
**功能：** 把天气数据保存为 JSON 文件
**知识点：** `with open`、`json.dump`、`ensure_ascii=False`、`indent=2`
**关键区分：** `f.write` 写"字符串"，`json.dump` 写"数据"（自动转 JSON 格式）

```python
def save_to_file(self, data: dict, filepath: str) -> bool:
    try:
        with open(filepath, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        print(f"[成功] 已保存到 {filepath}")
        return True
    except OSError as e:
        print(f"[错误] 文件写入失败: {e}")
        return False
```

### 模块 6：主程序整合（20分钟）
**功能：** 命令行交互（用户输入城市 → 查询 → 展示 → 保存）
**知识点：** `input()`、`if __name__ == "__main__"`、控制流
**踩过的坑（重要！）：**
- `if __name__` 必须**顶格**写（在类外面）——写在类里面会 NameError！
- `format_weather(data)` 是**展示文本**（给人看），`data` 是**原始数据**（存文件）——**展示用格式化结果，存储用原始数据！**

```python
if __name__ == "__main__":
    client = WeatherClient()
    city = input("请输入城市名: ").strip()
    data = client.get_weather(city)
    if data:
        print(format_weather(data))          # 展示用格式化文本
        client.save_to_file(data, f"weather_{city}.json")   # 存储用原始数据！
    else:
        print("查询失败，请稍后重试")
```
