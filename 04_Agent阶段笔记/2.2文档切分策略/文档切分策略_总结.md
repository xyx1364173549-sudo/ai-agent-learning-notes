# 2.2 文档切分策略（固定长度 + 重叠窗口）

## 一、总结

> **RAG 的第二环：把长文档切成小块（chunk），每块单独向量化、单独检索，让检索能精准命中"讲求根公式的那一小段"，而不是返回"整本书相关"。切分的核心技巧是重叠窗口——相邻块留部分重叠，保证边界附近的关键信息不因一刀切而丢失。**

这一步补齐了 2.1（文字→向量）和 2.3（向量库检索）之间的桥梁：向量化一次只能处理有限长度，检索的颗粒度也取决于块的大小。

---

## 二、对应知识点

### 知识点 1：为什么要切分？（两个原因）

| 原因 | 说明 |
|---|---|
| **向量化有长度限制** | embedding 模型一次只能处理几百到几千字，超长文本塞不进去 |
| **检索颗粒度太粗** | 学生问"二次方程求根公式是什么"，如果返回"整本书的向量"，只能知道"这本书相关"，定位不到"讲求根公式的那一段" |

**类比**：把一本厚书拆成"卡片"，每张卡片一个知识点。查资料时不用抱整本书，直接抽"求根公式"那张卡。

### 知识点 2：三种切分策略

| 策略 | 怎么做 | 优点 | 缺点 |
|---|---|---|---|
| 固定长度 | 按固定字符数切（如每 50 字一块） | 简单 | 可能在句子中间切断，破坏语义 |
| 按段落/标题 | 按文档天然结构切 | 保留语义完整 | 依赖文档格式规整 |
| **语义切分 + 重叠窗口** | 按语义找切分点，相邻块留重叠 | 最准、不丢信息 | 最复杂 |

### 知识点 3：重叠窗口（核心技巧）

固定长度切分的问题：一刀下去，可能正好把"**二次方程**"切成"二次方"+"程"两半，两个 chunk 都不完整，谁也匹配不上。

**解法**：让相邻 chunk 有部分重叠（如重叠 10 字），边界附近的关键信息**总有一个 chunk 是完整的**。

**实现的关键一行——步长**：

```
普通切分：    步长 = chunk_size        （块挨着块，无重叠）
重叠切分：    步长 = chunk_size - overlap   （每前进一次故意少走 overlap，下一块"回头看"）
```

```python
start += (chunk_size - overlap)   # 不是 start += chunk_size
```

代价是存储冗余（重叠部分存了两遍），换来的是**检索不丢信息**——这笔买卖在 RAG 里很划算。

### 知识点 4：边界条件（off-by-one 陷阱）

```python
while start < len(text):     # ✅ 正确：start 还没到末尾就继续
while start <= len(text):    # ❌ 错误：start 顶到末尾还切，会多出一块空字符串
```

当 `start == len(text)` 时，切片 `text[start:start+50]` 得到的是空字符串 `""`——白白多追加一块。

**反例验证**：text 长度 100、步长 50 时，`<=` 会切出 `[50, 50, 0]`（多一个空块），`<` 正确得到 `[50, 50]`。

## 三、对应代码段

```python
"""2.2 文档切分策略：固定长度 + 重叠窗口"""

# 模拟一份讲义（长文档）
text = ("大语言模型是基于Transformer架构的深度学习模型。"
        "Transformer的核心是自注意力机制，它允许模型并行地捕捉序列中"
        "任意两个位置之间的依赖关系。与传统的循环神经网络相比，"
        "Transformer能够更好地处理长距离依赖，因此成为现代大语言模型的"
        "基础架构。在此基础上，GPT等生成式模型通过海量语料的预训练，"
        "学会了预测下一个词，展现出强大的语言理解和生成能力。")

def chunk_text(text, chunk_size, overlap):
    chunks = []
    start = 0
    while start < len(text):                    # 边界：start 还没到末尾
        chunks.append(text[start:start+chunk_size])
        start += (chunk_size - overlap)         # 关键：步长 = 块长 - 重叠
    return chunks

# 调用：每块 50 字，重叠 10 字
chunks = chunk_text(text, chunk_size=50, overlap=10)

print(f"共切出 {len(chunks)} 块：")
for i, c in enumerate(chunks):
    print(f"\n[块{i}] (长度{len(c)}): {c}")
```

**运行结果**：

```
共切出 5 块：

[块0] (长度50): 大语言模型是基于Transformer架构的深度学习模型。Transformer的核心是自注意力机制，它允许模型并行地捕捉序列中
[块1] (长度50): 的核心是自注意力机制，它允许模型并行地捕捉序列中任意两个位置之间的依赖关系。与传统的循环神经网络相比，
[块2] (长度50): 与传统的循环神经网络相比，Transformer能够更好地处理长距离依赖，因此成为现代大语言模型的
[块3] (长度50): 依赖，因此成为现代大语言模型的基础架构。在此基础上，GPT等生成式模型通过海量语料的预训练，
[块4] (长度24): 基础架构。在此基础上，GPT等生成式模型通过海量语料的预训练，学会了预测下一个词，展现出强大的语言理解和生成能力。
```

**注意块0 末尾和块1 开头有 10 个字重叠**（"的核心是自注意力机制…"）——这就是重叠窗口生效的证据。

|---|---|---|
| #61 | 切分循环 `while start <= len(text)` | 当 text 长度被步长整除时，`start == len(text)` 会切出空字符串多一块（反例：100 字/步长 50 → [50,50,0]，应为 [50,50]）。**边界条件用"还没越界"的 `<`，不是"允许刚好越界"的 `<=`** |
