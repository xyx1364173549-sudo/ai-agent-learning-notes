2.1 Embedding 与向量化

阶段二 · RAG 根基 · 手算版理解原理
一句话总结：Embedding = 把文字变成一串数字（向量）。语义越相近的文字，向量靠得越近；用「余弦相似度」量化"有多近"。

核心机制：文字 → 向量 → 相似度

文字
"我喜欢吃苹果"
→
向量

知识点

① Embedding 是什么概念

把文字映射成向量，把"语义相近"变成"坐标距离近"这种可计算的数学关系。

类比：给文字发"坐标"。苹果和香蕉都是水果 → 坐标挨在一起；苹果和汽车 → 坐标隔老远。

② 词袋模型 Bag-of-Words向量化

数一句话里每个词出现几次，得到词频向量。

  • 词表 vocab：所有词去重后的列表，顺序 = 每个词在向量里的下标
  • 词频向量：长度 = 词表长度，每个位置 = 该词出现次数
类比："手工记账"——简陋但能懂原理。

③ 余弦相似度度量

cos(θ) = 点积 / (模长乘积)

  • 值 = 1 → 方向一致（最相似）
  • 值 = 0 → 垂直，无关
  • 值 = -1 → 方向相反

用夹角而非距离：夹角只看"方向"，不受文字长短影响。

④ zip 拉链函数语法

zip([1,1,1,1], [1,1,1,0]) → 对应位置配对 (1,1)(1,1)(1,1)(1,0)，配合 for 同时取两个向量同一位置的数。

类比："拉链"，把两条队伍按位置咬合。

⑤ 词袋模型 vs 真实 Embedding拔高认知

词袋模型真实 Embedding
谁定向量手工规则（数词频）神经网络（训练）
懂同义词❌ 苹果≠水果✅ 语义相近即相近
懂词序❌ 狗咬人=人咬狗✅ 能区分
维度随词表暴涨固定
关键：本质相同（文字→坐标→算距离），区别只在"谁定坐标"的聪明程度。真实 embedding = 神经网络学的"语义指纹"。

核心代码

def sentence_to_vector(sentence, vocab):
    vector = [0] * len(vocab)      # 先造"全 0"向量
    for word in sentence:
        index = vocab.index(word)  # 词 → 词表下标
        vector[index] += 1         # 该位置计数 +1
    return vector

def cosine_similarity(vec1, vec2):
    dot = sum(a * b for a, b in zip(vec1, vec2))
    norm1 = math.sqrt(sum(x * x for x in vec1))
    norm2 = math.sqrt(sum(x * x for x in vec2))
    return dot / (norm1 * norm2)
