# 2.1 Embedding 原理与向量化

## 一、总结

> **Embedding = 把文字变成一串数字（向量）。语义越相近的文字，向量靠得越近；用「余弦相似度」量化"有多近"。**

这一步是 RAG（检索增强生成）的根基——因为"搜索"的本质，就是把问题和资料都变成向量，再找"坐标最接近"的那份资料。

---

## 二、对应知识点

### 知识点 1：Embedding 是什么

- **定义**：把一段文字映射成一个向量（一串浮点数）。
- **核心价值**：把"语义相近"这种抽象感觉，变成"坐标距离近"这种可计算的数学关系。
- **类比**：给文字发"坐标"。苹果和香蕉都是水果 → 坐标挨在一起；苹果和汽车 → 坐标隔老远。

### 知识点 2：词袋模型（Bag-of-Words）

最朴素的向量化方式：**数一句话里每个词出现了几次**。

```
词表 = ["我", "喜欢", "吃", "苹果", "香蕉", ...]   ← 每个词有一个"下标"
"我喜欢吃苹果" → [1, 1, 1, 1, 0, ...]              ← 每个位置填该词的词频
```

- **词表（vocab）**：所有词去重后的列表，顺序决定了每个词在向量里的"位置"。
- **词频向量**：长度 = 词表长度，每个位置 = 该词出现次数。

### 知识点 3：余弦相似度

衡量两个向量"方向有多接近"：

```
cos(θ) = 点积 / (模长乘积)
          └ sum(a*b) ┘    └ sqrt(sum(a*a)) ┘
```

- 值 = 1 → 方向完全一致（最相似）
- 值 = 0 → 垂直，完全无关
- 值 = -1 → 方向相反

**为什么用夹角不用距离**：两段文字长短不同，向量长度也不同；夹角只看"方向"，不受长度影响，更适合衡量"语义方向"。

### 知识点 4：zip 拉链函数

`zip` 把两个序列按"对应位置"配对成元组：

```python
list(zip([1,1,1,1], [1,1,1,0]))
# → [(1,1), (1,1), (1,1), (1,0)]
```

配合 `for a, b in zip(vec1, vec2)`，每轮同时取两个向量同一位置的两个数，是"点积"所需的关键配对。

### 知识点 5：词袋模型 vs 真实 Embedding

| | 词袋模型（手算版） | 真实 Embedding |
|---|---|---|
| 谁定向量 | 手工规则（数词频） | 神经网络（训练出来的） |
| 懂同义词吗 | ❌ "苹果"≠"水果" | ✅ 语义相近就相近 |
| 懂词序吗 | ❌ "狗咬人"="人咬狗" | ✅ 能区分 |
| 维度 | 随词表暴涨 | 固定（几百~上千维） |

**关键认知**：两者本质相同（都是"文字 → 坐标 → 算距离"），区别只在"谁来定坐标"的聪明程度。词袋模型是"手工记账"，真实 embedding 是神经网络学的"语义指纹"。

## 三、对应代码段

```python
"""2.1 Embedding 原理：文本如何变向量 + 相似度如何算（手算版）"""
import math

sentences = [
    ["我", "喜欢", "吃", "苹果"],
    ["我", "喜欢", "吃", "香蕉"],
    ["今天", "天气", "很好"],
]

# ① 构建词表（去重）
vocab = []
for sentence in sentences:
    for word in sentence:
        if word not in vocab:
            vocab.append(word)

# ② 句子 → 词频向量
def sentence_to_vector(sentence, vocab):
    vector = [0] * len(vocab)      # 先造"全 0"向量，长度=词表长度
    for word in sentence:
        index = vocab.index(word)  # 词 → 词表下标
        vector[index] += 1         # 该位置计数 +1
    return vector

# ③ 余弦相似度
def cosine_similarity(vec1, vec2):
    dot = sum(a * b for a, b in zip(vec1, vec2))   # 点积
    norm1 = math.sqrt(sum(x * x for x in vec1))    # 模长1
    norm2 = math.sqrt(sum(x * x for x in vec2))    # 模长2
    return dot / (norm1 * norm2)                   # 余弦 = 点积 / (模长乘积)

# ④ 验证
v1 = sentence_to_vector(sentences[0], vocab)   # 苹果句
v2 = sentence_to_vector(sentences[1], vocab)   # 香蕉句
v3 = sentence_to_vector(sentences[2], vocab)   # 天气句

print("词表：", vocab)
print("苹果句向量：", v1)
print("苹果 vs 香蕉：", cosine_similarity(v1, v2))   # 0.75
print("苹果 vs 天气：", cosine_similarity(v1, v3))   # 0.0
```

**运行结果**：

```
词表： ['我', '喜欢', '吃', '苹果', '香蕉', '今天', '天气', '很好']
苹果句向量： [1, 1, 1, 1, 0, 0, 0, 0]
苹果 vs 香蕉： 0.75
苹果 vs 天气： 0.0
```

**结论**：苹果句和香蕉句共用 3 个词，相似度 0.75；苹果句和天气句零共用，相似度 0.0。语义越接近 → 向量方向越接近 → 余弦相似度越高。
