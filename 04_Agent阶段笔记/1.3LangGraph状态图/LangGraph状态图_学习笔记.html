LangGraph 状态图

任务 1.3 · 学习笔记 · 2026-08-23 · 含条件边与循环

一句话总结：LangGraph 把"调用 LLM 的步骤"组织成流水线，状态在节点间自动流转；条件边让流水线根据状态分叉，实现"答错重学、超限放弃"的动态流程。

一、基础：线性状态图

① State 状态 —— 工件规格

节点间共享数据，用 TypedDict 定义；total=False 表示字段可选。

class State(TypedDict, total=False):
    topic: str       # 主题（输入）
    lesson: str      # 讲解（节点产出）
    correct: bool    # 是否答对
    retry_count: int # 重试次数

② Node 节点 —— 工位（返回"更新"，不原地改）

def generate_lesson(state: State) -> State:
    lesson = ...
    return {"lesson": lesson}   # 返回更新，LangGraph 自动合并

③ 节点里复用 LCEL

chain = (
    ChatPromptTemplate.from_messages([("user", "讲解：{topic}")])
    | llm | StrOutputParser()
)
lesson = chain.invoke({"topic": state["topic"]})

④ 建图 + add_node + add_edge

graph = StateGraph(State)
graph.add_node("generate_lesson", generate_lesson)
graph.add_node("judge", judge)
graph.add_edge(START, "generate_lesson")
graph.add_edge("generate_lesson", "judge")

⑤ compile + invoke

app = graph.compile()
result = app.invoke({"topic": "递归"})

二、进阶：条件边与循环

⑥ 条件边 add_conditional_edges —— 分拣口

三个要素：出发节点、路由函数、映射表。让流水线根据状态分叉。

graph.add_conditional_edges(
    "judge",                    # ① 出发节点
    route,                      # ② 路由函数
    {
        "pass": END,               # ③ 映射表
        "retry": "generate_lesson",
        "give_up": END,
    },
)

⑦ 路由函数 —— 分拣员（返回方向字符串）

def route(state: State) -> str:      # 返回 str，不是 State
    if state.get("correct"):
        return "pass"              # 答对
    if state.get("retry_count", 0) >= 3:
        return "give_up"           # 超限放弃
    return "retry"                 # 重学

⑧ 循环 + 重试上限 —— 状态驱动的动态规划

用计数器记录循环次数，超限走 give_up，避免死循环。

def judge(state: State) -> State:
    correct = (state.get("answer") == "懂了")
    retry_count = state.get("retry_count", 0) + 1   # 每次 +1
    return {"correct": correct, "retry_count": retry_count}
讲解→ 判题→ 答对 END 答错<3 回讲解 答错≥3 放弃

💡 这就是你毕业论文"动态任务规划"的内核：流程根据状态动态调整
