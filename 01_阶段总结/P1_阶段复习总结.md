# 8️⃣ 推导式

## 核心概念

**用一行代码代替"for 循环 + 收集"**，Python 最具标志性的特性。Agent 代码里到处是它：过滤消息、批量转换数据、构建映射表。

## 三种形式

### 8.1 列表推导式

```python
# 基本：生成新列表
squares = [n ** 2 for n in numbers]                    # [1, 4, 9, 16, ...]

# 带 if 过滤（if 放最后 = 决定"要不要"）
evens = [n for n in numbers if n % 2 == 0]             # [2, 4, 6, 8, 10]

# if-else 放前面（= 决定"取哪个值"）
labels = [f"{n}-偶" if n % 2 == 0 else f"{n}-奇" for n in numbers]
# ['1-奇', '2-偶', '3-奇', ...]
```

### 8.2 字典推导式

```python
# 基本：{key: value for x in iterable}
lengths = {word: len(word) for word in words}          # {'apple': 5, ...}

# 首字母映射
first_letter = {word[0]: word for word in words}       # {'a': 'apple', ...}

# 带条件筛选
long_words = {word: len(word) for word in words if len(word) > 5}
```

### 8.3 嵌套推导式（Agent 实战）

```python
messages = [
    {"role": "user", "content": "hello"},
    {"role": "assistant", "content": "hi there"},
    {"role": "user", "content": "how are you"},
]

# 提取所有 user 消息的内容
user_contents = [m["content"] for m in messages if m["role"] == "user"]
# → ["hello", "how are you"]

# 生成 (role, 长度) 元组列表
pairs = [(m["role"], len(m["content"])) for m in messages]
# → [("user", 5), ("assistant", 8), ("user", 11)]

# 统计各 role 的数量（先取 roles 列表，再 count）
roles = [m["role"] for m in messages]
counts = {role: roles.count(role) for role in set(roles)}
# → {"user": 2, "assistant": 1}
```

## 语法模板（背下来）

```
[expr for x in iterable]                # 基本
[expr for x in iterable if cond]        # 过滤（if 在最后）
[a if cond else b for x in iterable]    # 选择（if-else 在前面）
{key: value for x in iterable}          # 字典
```

## 常见错误 ⚠️

1. **if 位置搞混**：
   - `if` 放最后 = **过滤**（决定要不要这个元素）
   - `if-else` 放前面 = **选择**（决定取哪个值）
2. **变量名拼写**：`spuares` → `squares`。拼写错误不影响运行但坑队友。

# 9️⃣ 魔术方法

## 核心概念

魔术方法（双下划线方法）让**自定义对象"伪装"成 Python 内置类型**，从而和 `len()`、`[]`、`for`、`print()` 等内置功能无缝配合。**Agent 的消息历史、工具注册表、配置管理都靠它们。**

## 魔术方法速查表

| 魔术方法 | 作用 | 触发场景 | 你的用法 |
|---------|------|---------|---------|
| `__init__` | 构造时初始化 | `obj = Class(...)` | 存模板/数据 |
| `__call__` | 对象可调用 | `obj(x)` | PromptTemplate |
| `__str__` | 用户友好显示 | `print(obj)` | Agent 类 |
| `__repr__` | 开发者调试显示 | `repr(obj)` | Agent 类 |
| `__len__` | 支持 len() | `len(obj)` | MessageHistory |
| `__getitem__` | 支持下标 | `obj[0]` | MessageHistory |
| `__setitem__` | 支持赋值 | `obj[k] = v` | Config |
| `__contains__` | 成员判断 | `k in obj` | Config |
| `__iter__` | 支持遍历 | `for x in obj` | MessageHistory |

## 9.1 `__call__` —— 让对象像函数一样被调用 ⭐

```python
class PromptTemplate:
    def __init__(self, template: str):
        self.template = template

    def __call__(self, **kwargs):
        return self.template.format(**kwargs)

t = PromptTemplate("你好 {name}，我是 {role}")
t(name="小轩轩", role="助手")    # 对象像函数一样被调用！
# → "你好 小轩轩，我是 助手"
```

**原理：** `obj(args)` 会被 Python 自动翻译成 `obj.__call__(args)`。

**核心价值：** 对象能**携带状态**（template），又能**像函数一样被传参调用**。当回调传入其他函数时，普通函数做不到"携带状态"，而 `__call__` 对象可以。

```python
def run_with_retry(func, input_data):
    return func(input_data)

run_with_retry(t, "小轩轩")    # 对象冒充函数 ✅（t 有 __call__）
```

## 9.2 容器协议 —— `__len__` / `__getitem__` / `__iter__` ⭐

```python
class MessageHistory:
    def __init__(self):
        self._messages = []

    def add(self, role: str, content: str):
        self._messages.append({"role": role, "content": content})

    def __len__(self):
        return len(self._messages)        # 支持 len(history)

    def __getitem__(self, index):
        return self._messages[index]      # 支持 history[0]

    def __iter__(self):
        return iter(self._messages)       # 支持 for msg in history
```

**对外界来说**，`history` 用起来就像列表（len/下标/遍历都能用），**内部实现由你说了算**——这就是"封装"。

## 9.3 Config 类 —— `__getitem__` / `__setitem__` / `__contains__`

```python
class Config:
    def __init__(self, data: dict):
        self.data = data

    def __getitem__(self, key):
        return self.data[key]             # config["model"]

    def __setitem__(self, key, value):
        self.data[key] = value            # config["max_tokens"] = 1000

    def __contains__(self, key):
        return key in self.data           # "model" in config

    def __repr__(self):
        return str(self.data)             # print(config)

    def keys(self):
        return self.data.keys()
```

## 核心概念：self（P1 最大的突破！）⭐

**self = 每个实例自己的"储物柜"钥匙。**

```python
class MessageHistory:
    def __init__(self):
        self._messages = []    # ✅ 加 self. = 实例属性，任何方法都能访问
        # _messages = []       # ❌ 不加 self. = 局部变量，函数结束就消失！
```

**规则：** 所有实例方法（无论普通方法还是魔术方法）**第一个参数必须是 self**。调用 `history.add("user", "你好")` 时，Python 自动把 `history` 作为 self 传进来。

## 常见错误 ⚠️（练习 9 踩过的坑）

1. **忘写 `self.` 前缀**：`_messages = []` 变成局部变量，类记不住。
2. **`len(self)` 无限递归**：在 `__len__` 里写 `len(self)` 会无限循环（`len` 又调 `__len__`），必须 `len(self._messages)`。
3. **`add` 里用 `self.role = role`**：每次调用覆盖上一次，应该往 `_messages` 里 append。
4. **多余 import**：`from operator import add` 没用上，要清理。

# 1️⃣0️⃣ 上下文管理器

## 核心概念

**with 语句 = 自动 try-finally 的语法糖**。保证资源（文件、连接、锁）无论是否异常都被释放。`with open(...)` 你天天在用，现在理解它背后的原理。

## with 的展开

```python
with open("data.txt") as f:
    data = f.read()

# 等价于：
f = open("data.txt")
try:
    data = f.read()
finally:
    f.close()          # ← 无论如何都会关闭！
```

## 10.1 内置用法（热身）

```python
# 读取
with open("config.json", "r", encoding="utf-8") as f:
    data = f.read()

# 写入
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("hello world")

# 读取验证
with open("data.txt", "r", encoding="utf-8") as f:
    print(f.read())    # hello world
```

## 10.2 自定义上下文管理器（类方式）⭐

```python
import time

class Timer:
    def __enter__(self):
        self.start = time.time()    # 进入：记录开始时间
        return self                 # 返回值给 as t

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.end = time.time()      # 退出：记录结束时间
        print(f"耗时 {self.end - self.start:.3f} 秒")
        return False                # False = 不吞异常（推荐）

with Timer() as t:
    sum(range(1000000))
```

**`__exit__` 的三个参数必须写**（Python 固定要求）：
```python
def __exit__(self, exc_type, exc_val, exc_tb):
    # exc_type: 异常类型（没异常就是 None）
    # exc_val:  异常对象
    # exc_tb:   追踪信息
```

**返回值含义：** `False` = 不吞异常（异常照常抛出）；`True` = 吞掉异常（慎用）。

## 10.3 @contextmanager 简化版 ⭐

```python
from contextlib import contextmanager
import time

@contextmanager
def timer():
    start = time.time()                    # yield 之前 = __enter__
    yield                                  # 这一行 = with 代码块
    print(f"耗时 {time.time() - start:.3f} 秒")   # yield 之后 = __exit__

with timer():
    sum(range(1000000))
```

**记忆方法：**
```
yield 之前 = __enter__（进入时）
yield 这行 = with 代码块
yield 之后 = __exit__（退出时）
```

**本质：** `@contextmanager` 就是 `__enter__`/`__exit__` 的精简版（用普通函数 + yield 分割前后）。

## 常见错误 ⚠️

1. **`__exit__` 忘写三个参数**：签名必须为 `(self, exc_type, exc_val, exc_tb)`。
2. **`__enter__` 忘了 `return self`**：`as t` 会拿到 None。
3. **`__exit__` 返回 True 吞异常**：会让错误悄悄消失，新手慎用。

# 🧩 贯穿性知识（P1 中打通的关键概念）

## 1. self = 实例的"个人储物柜"

```
类 = 模具（设计蓝图）
实例 = 用模具造出的产品
self = 产品的"个人储物柜"钥匙
```

- `self.xxx` = 实例属性，每个实例独立拥有
- 普通变量（无 self 前缀）= 函数内局部变量，用完即弃
- **所有实例方法第一参数必须是 self**，调用时 Python 自动传入

## 2. 容器协议 = "让对象假装成内置容器"

定义 `__len__`/`__getitem__`/`__iter__` 后，自定义对象就能用 `len()`、`[]`、`for`——**对外是 Python 标准语法，对内是自由实现**。

## 3. 魔术方法触发表（终极记忆）

| 你写的代码 | Python 背后调用的 |
|-----------|-----------------|
| `obj(x)` | `obj.__call__(x)` |
| `len(obj)` | `obj.__len__()` |
| `obj[i]` | `obj.__getitem__(i)` |
| `obj[k] = v` | `obj.__setitem__(k, v)` |
| `k in obj` | `obj.__contains__(k)` |
| `for x in obj` | `iter(obj)` → `obj.__iter__()` |
| `print(obj)` | `obj.__str__()` |
| `repr(obj)` | `obj.__repr__()` |
| `str(obj)` | `obj.__str__()` |
