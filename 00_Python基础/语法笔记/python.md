* 面向对象
  
  * 类的变量和成员方法
    
    * class 类名称： class 是关键字，表示要定义类
    
    * 对象 = 类名称（）
    
    * 类中的成员方法
      
      * def 方法体（self ，形参1，......）:方法体
      
      * 在方法内部，想要访问类的成员变量，必须使用self
  
  * 类
    
    * 类包含属性和行为 ，所以使用类描述现实世界事物是非常的合适的；类是程序的“设计图纸”，对象是基于图纸生产的具体实体
  
  * 面向对象，就是使用对象进行编程；设计类，基于类创建对象，并使用对象来完成具体的工作
  
  * 包含三大特性：封装，继承，多态
  
  * 封装
    
    * 私有成员，有部分属性和行为是不对使用者开放的
    
    * 成员变量和成员方法命名均以__作为开头；类的对象无法访问私有成员，类中的其他成员可以访问私有成员
  
  * 继承
    
    * 单继承：class 类名（父类名）：
    
    * 有单继承和双继承
    
    * 多继承：class 类名（父类1，父类2............,父类N）
    
    * 复写
      
      * 子类继承父类的成员属性后，对其不满意，进行复写；在子类中重新定义同名的属性或方法即可
      
      * 调用父类同名成员
        
        * super（）.成员变量|成员方法 / 父类名.成员变量|成员方法
  
  * 多态
    
    * 同一个行为，使用不同的对象获得不同的状态
