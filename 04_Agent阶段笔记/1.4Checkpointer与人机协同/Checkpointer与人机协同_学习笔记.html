Checkpointer 与人机协同

任务 1.4 · 学习笔记 · 2026-08-24 · 前置：LangGraph 状态图 + 条件边

一句话总结：Checkpointer 让流水线"记住"状态；人机协同（interrupt_before）让流水线在关键节点暂停，等人工确认后继续。两者配合实现"断点续传"。

一、状态持久化

① Checkpointer —— 档案柜

默认每次 invoke 独立运行（失忆）。挂上 Checkpointer 后，状态被存下来，下次能续上。

from langgraph.checkpoint.memory import MemorySaver

memory = MemorySaver()                        # 档案柜（内存版）
app = graph.compile(checkpointer=memory)      # 编译时挂上

② thread_id —— 档案编号

同一 thread_id 连续 invoke 共享状态，不同 thread_id 互相独立。

config = {"configurable": {"thread_id": "会话1"}}

字典套字典 = 给配置分类（config=容器，configurable=用户自定义类，thread_id=具体一项）

③ 多轮 invoke 续状态 —— 记忆的活证据

r1 = app.invoke({}, config)   # counter=1
r2 = app.invoke({}, config)   # counter=2（记得1）
r3 = app.invoke({}, config)   # counter=3（记得2）

没有 Checkpointer 时输出 1、1、1（失忆）

二、人机协同

④ interrupt_before —— 质检关卡

在指定节点前设质检关卡，跑到就暂停，把状态交人工检查。

app = graph.compile(checkpointer=memory, interrupt_before=["human_review"])

⑤ 断点续传 —— 暂停后恢复

result1 = app.invoke({"topic": "递归"}, config)
# 暂停：{'topic': '递归', 'lesson': '...'}   ← 无 approved

result2 = app.invoke(None, config)
# 继续：{'topic': '递归', 'lesson': '...', 'approved': True}

None = 继续上次没跑完的；暂停时前面节点已执行（有 lesson），后面没执行（无 approved）
